# ADR 0018 — 지식 그래프 온톨로지 확장 (서비스급) + 엣지 domain/range 제약

- **상태**: 채택 (2026-07-25)
- **맥락**: 현 온톨로지(노드 5·엣지 5)는 POC 최소라 서비스에 부족. 협력·계열·수혜/타격·인수·제품·테마·정책·공시유형(유상증자·무상증자·인수 등)·방향(증가/감소)을 못 담아 영상이 "왜 올랐나(인과·방향)"를 얕게 말함. §4 점검에서 **엣지 오용**(HAS_EVENT→섹터, SUPPLIES→섹터)도 확인 — 엣지가 5종·양끝이 엔티티면 통과할 뿐 "엣지가 양끝에 맞는지"는 검사 안 함.
- **결정**:
  - **노드 9종**: 기업·인물·사건·기관·섹터 + **제품·테마·정책·국가**.
  - **엣지 12종**: 기존 5 + **PARTNERS_WITH·AFFILIATE_OF·BENEFITS_FROM·HURT_BY·PRODUCES·ACQUIRES·REGULATES**. (BENEFITS_FROM/HURT_BY = 방향 있는 인과 = 알파① 핵심.)
  - **공시유형·방향 = 속성**(새 타입 아님) — 사건(Event)에 `event_type`(유상증자·인수·수주·실적…)·`direction`(긍정/부정/중립). 타입 폭발 방지.
  - **엣지 domain/range 제약** — 엣지마다 (주어 타입, 목적어 타입) 허용을 `EDGE_DOMAIN_RANGE`로 정의, 위반 삼중항 폐기. 예: HAS_EVENT는 목적어가 "사건"이어야(섹터면 폐기). §4 오용 차단. (㉞의 엔티티 타입검증 + 엣지-양끝 제약을 흡수·확장.)
  - **노드 타입은 `:Entity`의 속성**(`type`)으로 저장 — 9개 라벨 남발 대신. `:Stock`만 별도 라벨(시세 연계) 유지.
  - **정량 수치는 그래프 아님** — 주문량·가동률·매출액 등은 Postgres(사실). 그래프는 정성 이벤트·관계만. (뉴스가 "주문 증가"라 하면 사건+direction으로, 수치 자체는 별개 데이터 소스 과제.)
- **트레이드오프**: 어휘 확대 → LLM 오용·혼동↑ → domain/range 제약이 방어선(+프롬프트 예시 필수). 본문이 발췌라 제품·정책·수주 수율 낮을 수 있음(수집 광역화 ADR 0016과 시너지). direction은 LLM 주관(중립 허용, 뉴스 진술 의존). 확장 어휘로 재백필 필요(대량 재추출).
- **대안(기각)**: 공시유형·인수를 각각 새 엣지/노드로 — 폭발·관리난. 노드 타입을 Neo4j 라벨 9개로 — 초기 과함(후속 여지). 무제한 개방 관계(ADR 0014에서 이미 기각).
- **영향**: research `extract/relations.py`(어휘·프롬프트·파싱·domain/range 검증)·`graph/neo4j_repo.py`(속성·엣지 화이트리스트 12)·`consumer.py`(경미). `extract_graph` 시그니처·반환 골격 유지 → 배선 최소. 기존 5어휘 데이터와 혼재 → 신규부터, 재백필 후속. 계약 `api-contract-ontology.py`. **㉞ 흡수(별도 빌드 안 함)**.
- **관련**: [0014](개방형 NER), [0017](엔티티 타입검증 — 흡수), [0005](GraphRAG), [0004](알파①·인과), [0016](수집 광역화 — 소스 시너지). §4 학습 산물. 정량 데이터 소스 확장은 별도 과제(범위 밖).
