# ADR 0017 — 개방형 NER 엔티티 타입 검증 (일반어 노드 오염 차단)

- **상태**: 채택 (2026-07-24)
- **맥락**: 개방형 NER(ADR 0014)이 "노조·노사·이동통신사" 같은 **일반어를 엔티티 노드**로 만들고, 그게 관계까지 오염("삼성전자 COMPETES 노조"). §3/§4 학습 중 실 그래프에서 확인. 원인: 프롬프트는 엔티티 타입(기업·인물·사건·기관·섹터)을 요구하나 **반환 타입을 파싱하지 않고 이름만** 취함 → 타입 필터 부재. 스톱워드도 19개뿐.
- **결정**:
  - **엔티티를 `{name, type}`로 반환받아 허용 타입만 채택** — 타입이 `ENTITY_TYPES`(기업·인물·사건·기관·섹터) 밖(조직·일반·기타)이면 폐기. 구조적 근본책.
  - **스톱워드 보강** — 노조·노사·이동통신사 등 일반 조직·집합어 추가. 타입 필터가 못 잡는 알려진 노이즈의 안전망(노조가 "기관"으로 분류될 수 있어 병행 필수).
  - **하위호환** — LLM이 바레 문자열(레거시) 반환 시 type=미상으로 보고 기존 규칙(substring+스톱워드)만 적용. 전량 유실 방지.
  - **엔티티 정화 = 관계 정화** — 관계 채택은 `subject/object ∈ 채택 엔티티∪seed`(기존)라, 엔티티만 정화하면 관계는 자동으로 깨끗. 별도 관계 로직 변경 없음.
- **트레이드오프**: 타입 오분류 시 실제 기업 유실 위험(과폐기) → 관측 후 프롬프트·허용 타입 조정. seed(사전 종목)는 타입 무관 신뢰라 종목 안전. 프롬프트 출력 형식 변경 → 파싱 관대 유지로 취약성 완화.
- **대안(기각)**: 스톱워드 확대만 — 끝없는 두더지잡기(신조어·일반어 무한). 문법(주어/목적어) 파싱 도입 — 한국어 취약·새 의존(ADR 0014에서 이미 기각한 방향).
- **영향**: `services/research/app/extract/relations.py`(프롬프트·`_parse_graph`·`extract_graph`·`ENTITY_STOPWORDS`) + 테스트. `extract_graph` 시그니처·반환(Graph)·엣지 5종·근거 결속 불변 → consumer·backfill 배선 무변경. 기존 오염 데이터 정리는 후속(재백필). 계약 `api-contract-extract-quality.py`.
- **관련**: [0014](개방형 NER — 이 결정이 정제), [0004](알파① 정확·근거), [0005](GraphRAG). §3/§4 학습 산물. ㉜(news-feed 종목 태깅 오탐)와 다른 층(research 개방형 NER).
